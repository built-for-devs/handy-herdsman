## Summary
Animal type drives protocol timing and breeding-service eligibility, and the heifer→cow transition. "Calf"/"weanling" are display-only.

## Spec references
- §10b (Animal type & protocol eligibility) — binding.

## Requirements
- `cattle.animal_type` enum: `heifer`, `cow`, `bull`, `steer` (no `calf`).
- Age-stage labels derive from `cattle.dob` using `config('protocol.age_stages')` thresholds.

## Acceptance criteria
- [ ] `bull` and `steer` are **blocked** from any breeding/AI service with a clear validation message.
- [ ] A heifer **auto-promotes to cow on her first recorded calving** (`has_calved` → true), **not by age**.
- [ ] "calf" (<6mo) / "weanling·yearling" (6–12mo) / plain type (>12mo) are **computed from `dob`**, never stored; sorting/filtering by age stage is likewise computed.
- [ ] Timing keys off `animal_type`: heifer = 52–56h, cow = 60–66h post-V2.

## Config over code
Age-stage thresholds are config, adjustable without deploy.

## Tests
- [ ] bull/steer rejected from breeding service booking with the message.
- [ ] Calving event flips heifer→cow.
- [ ] Label derivation at 5mo, 8mo, 18mo boundaries.

## Definition of done
Enum enforced; eligibility + auto-promotion + computed labels covered by tests.
