TITLE: 6.4 — Multi-animal bookings & mixed-group blocking
MILESTONE: M6 — Booking & scheduling
LABELS: devin,booking
---
## Summary
One booking can cover multiple animals for per-head services; mixed cow+heifer AI is blocked because their V3 windows are ~8h apart.

## Spec references
- §10b (Multi-animal bookings)

## Requirements
- `booking_cattle` pivot for standard/per-head multi-animal bookings; `protocol_cattle` for same-type protocol groups.

## Acceptance criteria
- [ ] One booking **can cover multiple animals** for standard/per-head services; pricing applies per head with a **single visit minimum** (§10b, 8.2).
- [ ] For AI/protocol services, **mixed cow + heifer on the same booking is BLOCKED** at the timing step (V3 windows ~8h apart); the system **explains why and offers to split** into separate bookings/visits (§10b).
- [ ] **Same-type groups** (all cows OR all heifers) can share a protocol booking and one V3 window (§10b).

## Mobile behavior
Multi-select animals with big checkboxes; clear split-suggestion dialog.

## Config over code
Window separation derived from `config('protocol.windows')`.

## Tests
- 12-head vaccination = one booking, per-head price, one visit minimum.
- Mixed cow+heifer AI booking blocked with split offer.
- All-cows group shares one V3 window.

## Definition of done
Per-head multi-animal bookings + mixed-group blocking with split flow.
