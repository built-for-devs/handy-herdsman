TITLE: 6.7 — Staff booking & manual override
MILESTONE: M6 — Booking & scheduling
LABELS: devin,booking
---
## Summary
Jeff can create bookings himself via the same scheduler and can edit any booking/visit/charge — the escape hatch for every irregular situation.

## Spec references
- §4, §10b (Rescheduling, failed visits, staff override)

## Requirements
- Staff booking uses the same protocol-aware scheduler (6.1/6.2).
- Full staff edit authority over bookings/visits/charges.

## Acceptance criteria
- [ ] **Jeff (staff) can create any booking himself** via the same protocol-aware scheduler (§4).
- [ ] **Jeff can edit any booking, visit, or charge directly** — manual override is the escape hatch for every irregular case (§10b).
- [ ] **Reschedule = create a new appointment** — no special reschedule machinery (§10b).
- [ ] **Failed/aborted visits** (cow won't load, no chute, not contained) are **still billed at the normal visit rate** ($100 standard farm call); **no automated trip-fee logic** — Jeff's judgment/override (§10b).

## Mobile behavior
Staff can book/edit from phone; large edit controls.

## Config over code
Rates from `rate_config`.

## Tests
- Staff-created protocol booking runs full validation.
- Failed visit still bills normal rate; staff edit adjusts freely.

## Definition of done
Staff booking via shared scheduler; full override; reschedule-as-new; failed-visit billing.
