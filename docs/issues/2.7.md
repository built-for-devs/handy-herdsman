## Summary
Lightweight, staff-curated local resource directory — helps clients and ranks locally.

## Spec references
- §5.8 (Local resource directory).

## Requirements
- `directory_entries` (category, name, area, url, notes).

## Acceptance criteria
- [ ] Public directory of vets, nutritionists, **hoof trimmers**, other AI techs, etc.
- [ ] Staff-curated (create/edit in admin); category/area filtering.

## SEO
- [ ] Structured so it ranks for "cattle [service] near Waco".

## Mobile behavior
- [ ] Tap-to-call / tap-to-open links; legible list on phone.

## Definition of done
Curated directory live, filterable, SEO-oriented.
