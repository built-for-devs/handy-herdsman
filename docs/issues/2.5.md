## Summary
The primary lead magnet: a public calculator that educates and qualifies leads, and produces an instant informal proposal.

## Spec references
- §5.4 (AI Timing Calculator). Depends on **1.1** (protocol timing service).

## Acceptance criteria
- [ ] Input Visit 1 date/time + animal type (cow/heifer) → **V2 and V3 windows, visit count, plain-English "what each visit is and when"** (uses the 1.1 service).
- [ ] **Emailable/textable result = instant informal proposal**: enter contact → schedule + plan pricing sent via **Resend (email) / sent.dm (SMS)**.
- [ ] Prominent **homepage placement** + CTAs from services/blog pages.

## Config over code
Timing from `config/protocol.php` via the 1.1 service; pricing from `rate_config`.

## Mobile behavior
- [ ] Date/type entry trivially usable one-handed; results legible on phone.

## Tests
- [ ] Calculator output matches the 1.1 service for cow and heifer inputs.

## Definition of done
Public calculator live, emailable/textable proposal, prominent placement.
