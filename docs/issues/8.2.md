TITLE: 8.2 — Fee calculation
MILESTONE: M8 — Payments
LABELS: devin,payments
---
## Summary
Compute a booking's total from `rate_config` — plan + add-ons + fees — with the visit minimum applied correctly.

## Spec references
- §2, §5.2b, §10b (Money)

## Requirements
- Total = plan + additional-cow + distance fee + receipt fee + storage, all from `rate_config` / `services.price_rule`.

## Acceptance criteria
- [ ] Total computed from `rate_config`/`price_rule`; **no hardcoded prices** (§7).
- [ ] **Distance fee is per booking/protocol, not per visit** (one $30 covers all protocol visits) (§10b, 6.6).
- [ ] **Visit minimum (~$50) applies ONCE PER VISIT, not per service** — multiple per-head tasks bundled into one trip share **one** minimum (§10b).
- [ ] Per-head services price per head + the single visit minimum (§5.2b, 6.4).
- [ ] **No sales tax** anywhere (§10b).

## Config over code
Every price/fee from `rate_config`/`services.price_rule`.

## Tests
- 3-visit protocol at 20mi → one distance fee.
- Vaccinate + deworm same visit → one visit minimum, not two.
- Editing a `rate_config` value changes totals with no code change.

## Definition of done
Config-driven totals; per-booking distance fee; per-visit single minimum; no tax.
