## Summary
The time-sensitive per-cow reminders around breeding and calving.

## Spec references
- §5.7 (message catalog), §10b (Cattle status)

## Requirements
- Schedule reminders off breeding + calving dates (from preg-check/gestation).

## Acceptance criteria
- [ ] Around a breeding: **Insem +21d** (watch for return-to-heat), **+30d** (book preg check), **+60d** if no preg check booked (§5.7).
- [ ] Calving countdown: **Due −4wk / −2wk / −5d / −2d / −1d** + offer assistance; due-date-passed care check (§5.7).
- [ ] Countdown fires only after a **final `bred`** preg-check result (7.3) and uses the due date from 1.4.
- [ ] **Marking the animal `inactive` STOPS all its pending reminders immediately** (§10b, 4.1).
- [ ] These are category 1/3 messages; channel resolved via 9.2.

## Config over code
Offsets/templates as data/config; due date via `gestation_config`.

## Tests
- bred result schedules the countdown set; inactivating the cow cancels them.
- +21/+30/+60 scheduled from insemination date.

## Definition of done
Breeding + calving transactional reminders; inactivation cancels; gated on final results.
