TITLE: 4.4 — Data export
MILESTONE: M4 — Herd records portal
LABELS: devin,records
---
## Summary
Clients can export their own data at any time. Records are kept indefinitely; leaving deletes nothing.

## Spec references
- §10b (Records, permissions, data lifecycle)

## Requirements
- Export a team's cattle + records (e.g. CSV/JSON/zip) on demand.

## Acceptance criteria
- [ ] **Clients can export their data at any time** (§10b).
- [ ] **Client records are kept indefinitely; leaving does not delete anything** (§10b).
- [ ] Export is team-scoped (only their own data).

## Mobile behavior
One-tap "Export my data"; emailed link or download.

## Config over code
n/a (behavioral).

## Tests
- Export contains the team's cattle + records and nothing from other teams.

## Definition of done
Self-serve export; indefinite retention; tenant-scoped.
