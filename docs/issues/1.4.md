## Summary
Config-driven due-date estimator. Powers the public Due Date Calculator (2.6) and, in-app, the stored due date that drives calving reminders (§9.3).

## Spec references
- §5.4b (Due Date / Gestation Calculator) — binding.

## Requirements
- Read from `gestation_config` (breed → days; `__default__` = 283; `__heifer_offset__` = −1).
- Given breeding date + breed (+ cow/heifer), return an estimated due date **range**, plus calving-prep milestone dates (dry-off, −4wk/−2wk/−5d/−2d/−1d).

## Acceptance criteria
- [ ] Breed lookup falls back to `__default__` (283) for unknown/crossbreed.
- [ ] Heifer offset applied (~1–2 days earlier), from config.
- [ ] Output is **always a range/estimate, never a hard date** (±5 days is normal); copy says "expected around X".
- [ ] Bull-calf-gestates-longer is a **UI caveat, not a calculation** (calf sex unknown in advance).
- [ ] When a pregnancy is confirmed, the due date is computed from breeding date + breed and **stored** on the record to drive countdown reminders.

## Config over code
Breed table + heifer offset are editable data (`gestation_config`), no deploy.

## Tests
- [ ] Known breeds map to seeded days; unknown → 283.
- [ ] Heifer offset applied; cow not.
- [ ] Milestone dates computed correctly off the due date.

## Definition of done
Range output, config-driven, milestones correct; tested.
