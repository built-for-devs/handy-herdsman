TITLE: 10.1 — Cost & profitability reporting
MILESTONE: M10 — Reporting
LABELS: devin,reporting
---
## Summary
Profit per appointment/service/client, derived from records already captured — no separate bookkeeping.

## Spec references
- §5.6c (Cost tracking, profitability)

## Requirements
- Combine mileage (visit_completions/visits) + supply/drug cost (usage × `supplies.unit_cost`) + revenue (`payments`).

## Acceptance criteria
- [ ] Per-appointment capture: **mileage**, **supply/drug cost** (usage profile × unit costs), and **revenue** (§5.6c).
- [ ] Reports: **profit per appointment / per service type / per client** (revenue − supplies − drugs − mileage cost) (§5.6c).
- [ ] Surfaces **which services are actually worth doing** (§5.6c).
- [ ] **Mileage totals by period** for tax deduction (§5.6c).
- [ ] All derived from already-captured records — no separate bookkeeping.

## Mobile behavior
A few clear numbers, mobile-readable; not a dashboard nobody opens.

## Config over code
Costs from `supplies.unit_cost`; prices from `rate_config`.

## Tests
- Profit = revenue − (supplies + drugs + mileage) for a sample appointment.
- Mileage totals aggregate by period.

## Definition of done
Profit per appointment/service/client + mileage totals, from existing data, mobile-readable.
