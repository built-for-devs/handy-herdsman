MILESTONE: M3 — Clients, teams, onboarding

---
## Summary
Onboard a new client: create their team (tenant), capture required contact info, geocode their address once, and record the service agreement + liability waiver.

## Spec references
- §4 (Users, teams, access), §5.6 (agreement/waiver), §5.10 (geocode), §10b

## Requirements
- Create a `Team` (tenant) with the client as `client_owner`; create the `clients` record.
- Capture service agreement + liability waiver acceptance (timestamped: `agreement_signed_at`, `waiver_signed_at`).
- Geocode the address once (Google Geocoding), caching `lat`/`lng`/`cached_distance_miles`/`in_range`.
- Use Fortify / starter-kit auth — no custom auth.

## Acceptance criteria
- [ ] **Email REQUIRED** (identity/login) and **phone REQUIRED** (operational — Jeff drives out and may need a last-minute answer) (§5.7).
- [ ] Agreement + waiver acceptance recorded with timestamps (§5.6).
- [ ] Address geocoded **once at onboarding**; lat/lng + distance from the farm cached; `in_range` set (Distance Matrix called sparingly for cost control) (§5.10, §9).
- [ ] New client starts `status = new` (gates first booking to review — see 3.2).
- [ ] Laravel-first auth (Fortify/starter kit); Spatie assigns `client_owner`.

## Mobile behavior
Short, forgiving onboarding form; big tap targets; minimal typing; survives a dropped connection.

## Config over code
Farm origin coordinates + range threshold from config/`service_area_rules`.

## Tests
- Onboarding creates team + client + owner role.
- Agreement/waiver timestamps set.
- Geocode cached; in_range computed vs 15mi.

## Definition of done
Client + team created, required contact captured, waiver recorded, address geocoded once.
