## Summary
A clients-only bulletin board of cattle for sale — no public listings, no transactions.

## Spec references
- §5.9 (Cattle-for-sale board)

## Requirements
- Client toggles an existing `cattle` record to `for_sale` and picks which fields are shared (`for_sale_shared_fields`).

## Acceptance criteria
- [ ] **Clients only** can list — **no public listings** (§5.9).
- [ ] Client toggles an existing herd animal to for-sale and **picks which profile fields are shared** → a light public listing (§5.9).
- [ ] **Staff can also post** cattle Jeff knows others want to sell (§5.9).
- [ ] It's a **bulletin board, not a marketplace — no transactions** (§5.9).
- [ ] Photos from 4.3 can accompany a listing.

## Mobile behavior
One-tap "list this animal"; field-share checkboxes; big targets.

## Config over code
Shared fields chosen per listing (`for_sale_shared_fields`).

## Tests
- Toggling for_sale creates a listing exposing only chosen fields; no transaction flow.

## Definition of done
Client + staff listings, field-level sharing, no transactions.
