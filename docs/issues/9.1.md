## Summary
The reminder engine backbone: a daily scheduled command that queries date-offset windows and dispatches queued jobs, honoring quiet hours.

## Spec references
- §5.7, §7, §10b

## Requirements
- Laravel scheduler + queued jobs; a daily command populates/queries `reminders` and dispatches.
- Quiet-hours deferral via `config('reminders.quiet_hours')`; `reminders.quiet_hours_deferred_to`.

## Acceptance criteria
- [ ] A daily command queries date-offset windows and dispatches via **queued jobs** (Laravel scheduler/queue — no custom cron engine) (§5.7).
- [ ] **Quiet hours** (~8am–9pm, `config('reminders.quiet_hours')`): non-urgent messages **defer to the next allowed window** (so a 2-days-out reminder doesn't fire at 4am) (§5.7).
- [ ] **On-call/emergency confirmations bypass quiet hours** — a 2am calving message goes (categories with `bypasses_quiet_hours=true`) (§5.7, §10b).
- [ ] Idempotent (no duplicate sends on re-run).

## Config over code
Quiet hours + categories from `config('reminders')`.

## Tests
- Non-urgent reminder at 4am defers to 8am.
- Category 1 emergency sends immediately at 2am.
- Re-running the daily command doesn't double-send.

## Definition of done
Scheduler + queue backbone; quiet-hours deferral; emergency bypass; idempotent.
