## Summary
Blood preg checks are a two-stage event; palpation is immediate. Downstream nurture must wait for a final result.

## Spec references
- §10b (Preg check results) — binding; §5.2b (lab fee).

## Requirements
- `preg_checks` (`method` blood/palpation, `lab_requested`, `state` pending/open/bred/recheck, `recorded_by`).

## Acceptance criteria
- [ ] Blood: draw at the visit → **optional +$15 lab confirmation, only charged if the client opts in** → state **`pending`** until Jeff records the final result.
- [ ] Final states: **`open` / `bred` / `recheck`**; **Jeff records results, clients do not**.
- [ ] **Downstream nurture fires ONLY on a final result, never on `pending`**: `bred` → due date computed (1.4) + calving countdown scheduled; `open` → rebreed prompt; `recheck` → schedule another check.
- [ ] Palpation (after 4 months) is **immediate/definitive** — no pending state, no lab fee.

## Config over code
Lab-confirmation fee from `rate_config`.

## Tests
- [ ] `pending` fires no nurture; transition to `bred` schedules due-date + countdown; `open` fires rebreed; `recheck` schedules recheck.
- [ ] Lab fee charged only when opted in.
- [ ] Palpation skips pending.

## Definition of done
Async blood flow + immediate palpation; nurture gated on final state; tested.
