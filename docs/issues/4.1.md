TITLE: 4.1 — Cattle profiles
MILESTONE: M4 — Herd records portal
LABELS: devin,records
---
## Summary
Cattle profile CRUD in the client portal, with active/inactive status and the computed age-stage label from M1.2.

## Spec references
- §5.5, §10b (Cattle status), §10b (Animal type)

## Requirements
- Profile from `cattle` (reg_name, herd_number, dob, breed, animal_type, a2a2, notes).
- `status` active/inactive; display computed age-stage label (1.2).

## Acceptance criteria
- [ ] **Marking a cow `inactive` STOPS all pending reminders for that animal immediately** (§10b).
- [ ] Inactive animals stay in records/history — **never deleted**; **nothing hard-deletes, soft-delete only** (§10b).
- [ ] Display uses the **computed age-stage label** from `dob` (1.2), not a stored "calf" type.
- [ ] Profiles are team-scoped (tenant isolation).

## Mobile behavior
Scannable profile, big edit targets, minimal typing; photo thumbnails (4.3).

## Config over code
Age-stage thresholds via `config('protocol.age_stages')`.

## Tests
- Inactivating an animal cancels its pending reminders.
- Soft delete only; history retained.

## Definition of done
Cattle profiles with status + computed labels; inactivation stops reminders; soft-delete only.
