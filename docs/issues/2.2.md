## Summary
Public Services and Pricing pages, both rendered entirely from data.

## Spec references
- §5.2, §5.2b, §6 (`services`).

## Requirements
- Render from the seeded `services` table + `rate_config`.

## Acceptance criteria
- [ ] Both pages render **from `services` + `rate_config` — no hardcoded copy or prices**.
- [ ] Adding/editing a service or price is data entry, not a deploy.
- [ ] "Not offered" items shown as **trust signals**: castration (case-by-case, off-platform), hoof trimming (→ directory), anything requiring a vet license.

## Config over code
Prices/services never hardcoded; pulled live so they can't go stale.

## Mobile behavior
- [ ] Cards/lists legible one-handed; tap-to-expand detail.

## Tests
- [ ] Page reflects a changed `rate_config` value without code change.

## Definition of done
Data-driven services + pricing; trust-signal exclusions shown.
